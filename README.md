An HTML CSS and JS radio terminal project where the user acts as an operator and monitors the channels. A mysterious channel is known to appear that can corrpupt the user's device and get access to all the information. The operator must observe the radio transmission and see if everything is going on properly and if unknown disturbances come, then terminate the program.

Side Note: This is all fictitious except the user device details and the system will not be actually hacked/infected or anything along those words. There is no actual virus in the program.

Built as a project for Hack Club's Zone Out YSWS [You Ship We Ship] Program.
